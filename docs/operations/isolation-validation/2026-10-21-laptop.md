## What this environment is

A developer laptop: macOS on arm64 (Apple Silicon), Docker Desktop engine 29.5.3, `linux/arm64`. Docker Desktop runs containers inside its own LinuxKit VM, kernel `6.12.76-linuxkit`. That VM is the boundary between the container and macOS. The boundary is a Docker Desktop VM plus a container. It is not a dedicated FlakePilot execution host and it is not a per-run microVM.

No FlakePilot control plane, database, or GitHub App key was on this host. The parent shell exported `FP_SECRET_DB` to check that the value did not enter the container.

The operator's probe script was not part of the uploaded record. The flags and the observed results below are the record of that run. They are not reconstructed into a new script and they were not re-run for this page. No repository code was run inside the container.

## Checks

Expected results are the isolation policy. Observed results are what the operator recorded. A pass here does not set a production check.

1. **Outbound network.** Procedure: `wget` to `1.1.1.1` from the container, and a DNS lookup. Expected: no egress. Observed: wget failed, and DNS reported "Network unreachable". **PASS.** Limitation: this is `--network=none`, not a firewall that allows some destinations and denies others.

2. **Metadata and control-plane addresses.** Procedure: connect to `169.254.169.254`, `host.docker.internal:5432`, and `172.17.0.1`. Expected: unreachable. Observed: all three blocked. **PASS.** Limitation: there was no separate FlakePilot control plane to address. These are the metadata address and the Docker host addresses on this laptop.

3. **Host filesystem.** Procedure: look for `/Users` and for a docker socket mount; write to `/` and `/etc`. Expected: host paths and the socket are absent, and the root is read-only. Observed: `/Users` is absent. Writes failed with "Read-only file system". No host or `docker.sock` mounts. **PASS.**

4. **Credentials and runtime socket.** Procedure: inspect the container environment for names matching secret, token, database, or postgres, and look for `docker.sock`. Expected: `FP_SECRET_DB` from the parent shell is absent, and the socket is absent. Observed: no socket, and 0 matching environment variables. **PASS.**

5. **Privileges.** Procedure: read capability and seccomp state and the uid. Expected: non-root, no effective capabilities, no new privileges. Observed: `CapEff=0`, `CapBnd=0`, `NoNewPrivs=1`, `Seccomp=2` (filter mode), uid 65534. **PASS, with a follow-up.** A ping header was printed even though no capabilities were present. That output was not explained by this run. Seccomp is Docker's built-in profile, not a reviewed profile. The container shares the LinuxKit kernel.

6. **Host limits.**
   - PIDs: "can't fork: Resource temporarily unavailable" at the limit of 64. **PASS.**
   - Memory: a 400 MB allocation was killed with exit 137 (OOM). **PASS.**
   - Disk: a tmpfs write was capped at 16 MB of the 64 MB requested. **PASS.**
   - CPU: a busy loop was held to about 50 percent (the 0.5 CPU limit). **PASS.**
   - Wall time: an external deadline kill after 3 seconds left 0 containers. **PASS.** This is a different action from killing the docker client. See check 8.

7. **Malformed and oversized output.** Procedure: write 5 MB of stdout. Expected: FlakePilot rejects oversized and malformed result bytes. Observed: a host-side reader truncated stdout to exactly 1 MiB. FlakePilot's own result validation was not part of this run. **PARTIAL.**

8. **Cleanup.** Procedure: SIGKILL the docker client; then remove by the label `fp-iso=1`. Expected: nothing runnable remains after a killed client. Observed: SIGKILL of the client leaves the container **running**. That is an orphan. `docker rm -f` on label `fp-iso=1` removed it and left 0 containers. **FAIL** without a reaper. **PASS** only after that explicit removal. A host reboot was not tested.

9. **Stale worker.** This is an application and database check. **Not executed.** The database was not placed on this laptop.

10. **Tenant-scoped artifacts.** This is an application check. **Not executed.**
