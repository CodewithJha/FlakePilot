# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub security advisories: on this repository, open the **Security** tab and choose **Report a vulnerability**. Don't open a public issue for a vulnerability.

Include what you found, how to reproduce it, and the impact you expect. Don't include real credentials or other people's data.

## Supported versions

None yet. FlakePilot is pre-alpha and has no releases. Fixes land on the `main` branch.
